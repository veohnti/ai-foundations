# Campus Customs — React board

React + TypeScript + Vite dashboard for the HW5 agent team. It talks to the FastAPI backend at http://localhost:8000.

```bash
npm install
```

```bash
npm run dev
```

Then open http://localhost:5173 (the port is fixed because the backend only allows this origin). The setup steps are in `../README.md`, and the design notes are in `../output/design.md`.
